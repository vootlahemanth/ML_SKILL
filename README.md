# 2520030031 ML Skill Programs

All 11 ML programs include their own local `dataset/` folder and CSV file.

1. Titanic EDA + ML Lifecycle
2. Titanic Preprocessing Pipeline
3. Adult Income Feature Engineering + EDA
4. California Housing Linear Regression + Regularisation
5. Titanic Logistic Regression
6. Diabetes Severity Multinomial Logistic Regression
7. Auto MPG Regression + Scaling + Encoding
8. Heart Disease Decision Tree
9. Heart Disease Random Forest
10. Heart Disease XGBoost + LightGBM + SHAP
11. Wine Quality Decision Tree + Random Forest

Install:
```bash
pip install -r requirements.txt
```

The included CSVs are generated practice datasets matching the required columns, so all projects can run locally without first downloading data.
